InterviewAI is a production-ready AI-powered interview preparation platform designed to help students and job seekers prepare smarter for placements and interviews.

Users can upload their resume, provide a job description, and receive a personalized AI-generated report containing:

- Match Score
- Technical Questions with Answers
- Behavioral Questions with Answers
- Skill Gap Analysis
- 7-Day Preparation Plan
- ATS Optimized Resume PDF
- Report History Dashboard

---

## 🌟 Features

- Secure Authentication using JWT & Cookies
- Resume PDF Upload & Parsing
- AI-Powered Interview Question Generation
- Match Score Evaluation

- Resume PDF Generation

# 🚀 Installation & Setup

## Clone Repository

```bash
git clone https://github.com/anubhav-2212/Interview-AI.git
cd Interview-AI
```

## Backend Setup

```bash
cd server
npm install
npm run dev
```

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

## Environment Variables

Create `.env` inside `server`

```env
PORT=8001
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
NODE_ENV=development
```
